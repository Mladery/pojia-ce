# 破甲一键通 8.53-CE

免安装单文件可执行文件。不用装 Python，不用装依赖，下载后放任意目录直接跑。

## 下载

| 平台 | 文件 |
|---|---|
| Windows x64 | `pojia-ce-windows-x64.exe` |
| Linux x64 | `pojia-ce-linux-x64` |
| macOS Apple Silicon | `pojia-ce-macos-arm64` |
| macOS Intel | `pojia-ce-macos-x64` |

Linux / macOS 下载后先 `chmod +x`。macOS 首次运行可能被 Gatekeeper 拦，右键 → 打开，或 `xattr -d com.apple.quarantine <文件>`。

双击直接进图形界面；想走命令行菜单加 `--menu`，带参数时（`--status` / `--apply` 等）不会抢。

## 校验

两条**互相独立**的通道，别只看一条 —— 哈希和文件在同一处发布，能改仓库的人可以同时改掉两者。

1. **签名（Windows）**：`tools/verify-windows.ps1` 比对仓库里钉死的公钥证书
   `tools/codesign/pojia-signing.cer`（SHA-256 `ee95267b61a4965829338d80a792d3b3810d6b0c2d8045d6842ce1fb22c8e413`）。
   私钥不在仓库里，伪造不出来。
2. **`SHA256SUMS.txt`**：四个平台的校验和。Linux / macOS 没有签名，只有这一条路。

```bash
sha256sum -c SHA256SUMS.txt        # Linux
shasum -a 256 -c SHA256SUMS.txt    # macOS
```

## 这个版本

这一版是**给没用过命令行的人重做的界面**，外加把两个 DSH 开关从 `--help` 里搬出来。

- **主行动收敛成一个按钮。** 顶部一个「一键破甲」加一个「先检测一下（只看不改）」；`还原成原版` 留在「其他操作」，诊断 / 预演 / 快照 / 对比收进默认折叠的「更多工具」。功能一个没少，只是不再让八个按钮平铺抢注意力。
- **黑话配白话。** 页面顶部一段默认折叠的说明：破甲是什么、会改电脑上的什么、后悔了怎么办、源码在哪。答案写的是影响范围 —— 只改安装目录里的提示词和配置文件，改前备份，不动系统设置、不动代码、不动账号。
- **跑完直接给结论。** 右上角状态胶囊四态：`待命中 / 处理中… / 完成 / 有问题，看下面`。不用再翻三百行终端找哪句是红的。
- **DSH 破甲方式可选（界面）。** `--dsh-mode inject|preset` 现在是两个单选卡片：`改配置文件`（所有模式生效，最彻底）或 `只加一个模式`（不动官方文件，DSH 升级也不冲掉）。默认仍是 `inject`，和命令行默认值一致。
- **Git Bash 开关进界面（Windows）。** 「让 DSH 改用 Git Bash 执行命令」—— 自动准备便携版 Git Bash，不安装、不改系统设置，重启 DSH 后生效。预演也会如实报出会接管哪份 Git，但**不会**触发下载（`ensure_git_bash` 只在真执行时调用）。
- **仓库地址挂上页面。** 页脚和帮助段各一处，地址在 Python 侧单源，换仓库只改一个常量。
- **接口收紧。** `build_cmd()` 四参化；`do_POST` 对 `dsh_mode` 做白名单校验、`git_bash` 强制转 bool。两个可选项只在「预演 / 破甲」且目标含 DSH 时才追加，`还原` 不传。
