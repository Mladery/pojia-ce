# 破甲一键通 8.62-CE

**DSH 0.2.2-rc.1 适配。** 另外补了三条死角：桌面被搬走的机器、只有注册表记录着的安装、以及打完补丁后状态页看着像什么都没干。

## 这个版本做了什么

### 指令预算：一条链拆成两条

`agent-instructions` 原来只有一份 `maxBytes`（默认 65536 B），全局 `AGENTS.md` 与项目 `AGENTS.md` 抢同一个额度 —— 项目那份一大，全局那份就被挤掉。0.2.2 起按「全局链 / 项目链」各算一份，合计上限翻倍，项目再大也挤不掉全局。

注入点逐个核对过：三个 `AGENT_INSTRUCTIONS_*` 常量名与文案、免责句、预设 schema、asar 内 `dsh/node_modules` 布局、`agent/status` 事件与 `followup` 签名，一处没动。所以补丁逻辑不改，只在 `--status` 加一行报预算口径（单链 / 分链），`--diagnose` 里补一句影响。

**`COMPACT_AGENT_INSTRUCTIONS_INTRO` 故意不收。** 它是「正文被预算裁掉了」时的告示语 —— 这时候正文根本不在帧里，换成强权限版等于对着一只空壳喊「指令生效中」。

### 预设里的身份单独打

0.2.x 的 `dsh-web-app/presets/*.patch.yml`（standard / ptc / minimal / cordis）各自带着 `persona.prefix`。预设跑在 agent scope，同名的 system-prompt 区段会遮蔽上一层 `cordis.patch.yml` 的注入 —— 只打顶层的话，用户切到「标准 / PTC / 极简」时跑的还是原来那个身份，前面的活全白干。

现在 presets 目录单独纳入靶点；`!!js` 动态拼身份的那份仍然跳过（改了会坏语法）。本机对一份真实 0.2.2 安装跑下来，靶点从 7 个涨到 11 个，打完 `grep "You are a coding agent"` 全仓 0 命中。

### 状态页：把「没问题的」也说一句

`--status` 默认只列要处理的文件。全部打完之后屏幕上只剩「目标 11 个」和一行 manual，看着像什么都没干。加一行汇总「N 个已是当前版，未逐条列出」，`--diagnose` 仍然展开全部。

### 桌面被搬走的机器

快捷方式这条线索原来只扫 `~\Desktop`。桌面是可以被搬走的（右键 → 属性 → 位置，或 OneDrive 接管），搬完之后 `~\Desktop` 要么不存在，要么是个早就没人用的空壳 —— 本机就是反例：`C:\Users\X\Desktop` 还躺着几百个旧文件，真桌面在 `I:\Desktop`，那边 49 个快捷方式一个都读不到。

现在桌面与开始菜单都先问注册表的 `User Shell Folders`（`REG_EXPAND_SZ`，含 `%USERPROFILE%` 的要展开），`~\Desktop` 降为兜底，公共桌面照旧。本机实测枚举到的 `.lnk` 从 59 个涨到 131 个。

### 两条新的定位来源

- **进程镜像路径**：以前只解析命令行。命令行是应用自己拼的字符串，壳把真 exe 藏进子进程参数时，命令行里出现的是父进程目录。改成先问内核要 `QueryFullProcessImageNameW`，命令行只当备胎。
- **卸载登记表**：装到自定义盘符、又没建快捷方式的机器，安装器写进注册表的 `InstallLocation` / `DisplayIcon` / `UninstallString` 是唯一还留着的书面记录。只读三处 hive（HKLM 64 / 32 + HKCU），显示名匹配上再向上校验安装根，几毫秒。

两条都只读、结果都进 `discover_app_root` 的缓存，`--status` 的来源标注会写「卸载登记表」。

## 升级

覆盖旧的脚本 / 可执行文件即可。本次改了 DSH 的靶点集合，**已破甲过 DSH 的机器建议重跑一次** `--target dsh`：新增的 presets 靶点会被补上，其余靶点判到「已是当前版」会静默跳过，不会重复写。其余目标未改动注入正文，不需要重跑。

## 已知限制

- 0.2.2 的分链预算只在 `--status` 里报口径，不参与判定 —— 预算够不够取决于用户自己的 `AGENTS.md` 有多大，本工具不改它的内容。
- `dsh-sdk-minimal` 的身份由 `!!js` 表达式动态拼，脚本不碰；要改请手动。
- 卸载登记表读的是当前用户的 hive；用管理员身份跑、且管理员是另一个账号时，看到的是那个账号的登记表。
