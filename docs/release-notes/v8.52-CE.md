# 破甲一键通 8.52-CE

免安装单文件可执行文件。不用装 Python，不用装依赖，下载后放任意目录直接跑。

## 下载

| 平台 | 文件 |
|---|---|
| Windows x64 | `pojia-ce-windows-x64.exe` |
| Linux x64 | `pojia-ce-linux-x64` |
| macOS Apple Silicon | `pojia-ce-macos-arm64` |
| macOS Intel | `pojia-ce-macos-x64` |

Linux / macOS 下载后先 `chmod +x`。macOS 首次运行可能被 Gatekeeper 拦，右键 → 打开，或 `xattr -d com.apple.quarantine <文件>`。

可执行文件和直接跑脚本行为一致：`persona.md` 放在可执行文件旁边就会被读到，`状态/` 和日志也落在旁边。

## 校验

两条**互相独立**的通道，别只看一条 —— 哈希和文件在同一处发布，能改仓库的人可以同时改掉两者。

1. **签名（Windows）**：`tools/verify-windows.ps1` 比对仓库里钉死的公钥证书
   `tools/codesign/pojia-signing.cer`（SHA-256 `ee95267b61a4965829338d80a792d3b3810d6b0c2d8045d6842ce1fb22c8e413`）。
   私钥不在仓库里，伪造不出来。
2. **`SHA256SUMS.txt`**：四个平台的校验和。Linux / macOS 没有签名，只有这一条路。

```bash
sha256sum -c SHA256SUMS.txt        # Linux
shasum -a 256 -c SHA256SUMS.txt    # macOS
```

## 这个版本

- **单文件包终于带上图形界面。** `pojia-ce --gui` 起本机网页 UI，浏览器自动打开。界面是打包时塞进包里的数据文件，由核心用 runpy 在进程内拉起；页面里的每个动作把 exe 自己当子进程跑，输出照样实时流回页面。不想自动开浏览器就设 `POJIA_GUI_NO_OPEN=1`。
- **核心用 Cython 预编译。** 不是为了加壳 —— 源码一行没少，clone 下来就是可读的 Python；编译只是省掉每次启动把 9929 行编译成字节码。实测 `--version` 0.371 s → 0.286 s（1.30×），`--status all` 8.54 s → 7.72 s（1.11×）。扫盘类操作大头是磁盘 IO，别指望它变快。
- **构建链路收进 `tools/build_exe.py`。** `--add-data` 的分隔符（Windows `;` / POSIX `:`）、Cython 那几步、hidden-import 扫描都在脚本里；Cython 装不上自动退回纯源码打包，不让发布变红。
- **新增 `tools/gui_smoke.py`，CI 每平台跑一遍。** 起界面 → 取地址 → 拉首页 → 点一次「检测状态」。GUI 是 runpy 从数据文件跑的，漏了 `--add-data` 时 `--version` / `--status` 全绿，只有敲 `--gui` 那一刻才炸。
- **许可归属写清楚。** `LICENSE` 里两行版权并列（上游 `z91772524-ai` / 本仓库 `Mladery`），许可正文一字未改；新增 `NOTICE` 说明哪部分是 `536ece2` 的、哪部分是本仓库新增的。不放两份 MIT 正文 —— 多一个 `LICENSE*` 会让许可证识别判成「双许可 / 冲突」。
