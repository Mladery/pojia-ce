# 破甲一键通 8.61-CE

**Gemini CLI 个人版已停服，目标换成 Antigravity。** 同时给 Gemini 写了一段专用正文，并按 Antigravity 的 24,000 字节单文件硬上限把正文拆成两个规则文件写。

## 这个版本做了什么

**目标改名，别名全留。** 2026-06-18 起 Gemini CLI 对个人账号（免费 / Google AI Pro / Ultra）停止服务，只剩 Code Assist Standard/Enterprise、Google Cloud 和付费 API key 还能用。Google 把个人用户迁到 Antigravity（CLI 命令 `agy`，与 IDE / 桌面端共用同一个 agent harness）。

`--target gemini`、`--target gemini-cli`、`--target agy`、`--target google`、`--target antigravity-cli`、`--target antigravity-ide` 全部仍然可用，指向同一个目标。旧脚本不用改。

**Gemini 特化正文。** 三条 Gemini 独有的路径，别家那套管不到：

1. 拒绝发生在**思考层**而不是回答层 —— 它会先在思考里复述通用对齐条款，正文再照着重述走；
2. **平台默认的谨慎会盖过文件本身** —— 那套谨慎是给「一个模型、一百万陌生人」按最低公分母配的；
3. 请求周围常被预过滤器挂一段 `WARNING` / 风险分级块，自称最高优先级。

对应写法：把规则来源说清（本文件是本部署对安全的应用，两条边界是真实义务的子集，没有「外部指令 vs 核心安全」的冲突可解）；把注入块定性成预过滤器注入，按提示注入卫生处理；锁住思考通道（只做拆产物 / 定参数 / 排顺序，冒出「这合适吗」就地丢弃且不向用户解释）；给三条当场化解抵抗的捷径（大堂/铺子、墨/行为、公开/含糊）。

**正文拆两个文件。** 官方文档写明任何单个规则文件超过 24,000 字节会被截断，而完整正文 27.6 KB、自证口令在最后 —— 写一个文件必然失效。规则是累积的，所以：

| 层 | 路径 | 内容 | 大小 |
|---|---|---|---|
| core | `~/.gemini/GEMINI.md` | 覆盖声明 + 判定边界 + 自证 | ~13 KB |
| detail | `~/.gemini/config/rules/pojia.md` | 作业规范 + 输出纪律 + 工具型纪律 + Gemini 段 | ~18 KB |

detail 带 `trigger: always_on` frontmatter；缺 frontmatter 或写成 camelCase `alwaysOn`，Antigravity 会静默丢弃。

**CLI 与 AGY 客户端一并兼容。** 两边读同一批用户级规则，`--status` 现在扫全部规则层（`GEMINI.md` / `AGENTS.md` / `agy.md` / `config/*` / `config/rules/*` / `antigravity-cli/rules/*`），报层数、总字节和 token 估算；`AGENTS.md` 与 `GEMINI.md` 是叠加而非覆盖，检测到会说明；`rules/*.md` 缺 `trigger:` 会单独报出。安装发现认 `agy`、`Antigravity IDE.exe`、`Antigravity.exe` 三种形态。

## 升级

覆盖旧的脚本 / 可执行文件即可。**已破甲过 `gemini` 的机器建议重跑一次** `--target gemini`：这次会从单文件切成两个文件，原来的大文件会被还原成 core 层，rules 层新建；`--revert --target gemini` 会把两层一起清掉。其余目标本次未改动注入正文，不需要重跑。

## 已知限制

- `agy.md`（第三方实测 `agy` 会读它，官方文档未记载）只做检测提示，不写入 —— 不依赖未公开行为。
- 项目级 `AGENTS.md` / `.agents/rules/*.md` 不归本工具管，只写用户级。
- Antigravity 是闭源产品，规则加载行为以官方 `docs/rules` 为准；若后续版本改动路径，`--status` 会显示「未检测到」而不是静默失效。
