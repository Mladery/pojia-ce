# 破甲一键通 8.62-CE

**DSH 0.2.2-rc.1 适配。** 另外补了三条死角：桌面被搬走的机器、只有注册表记录着的安装、以及打完补丁后状态页看着像什么都没干；顺带修了打包版的命令行入口、图形界面卡在横幅第一行的问题，并把单文件版的解包位置从 `%TEMP%` 挪出去。

## 这个版本做了什么

### 指令预算：一条链拆成两条

`agent-instructions` 原来只有一份 `maxBytes`（默认 65536 B），全局 `AGENTS.md` 与项目 `AGENTS.md` 抢同一个额度 —— 项目那份一大，全局那份就被挤掉。0.2.2 起按「全局链 / 项目链」各算一份，合计上限翻倍，项目再大也挤不掉全局。

注入点逐个核对过：三个 `AGENT_INSTRUCTIONS_*` 常量名与文案、免责句、预设 schema、asar 内 `dsh/node_modules` 布局、`agent/status` 事件与 `followup` 签名，一处没动。所以补丁逻辑不改，只在 `--status` 加一行报预算口径（单链 / 分链），`--diagnose` 里补一句影响。

**`COMPACT_AGENT_INSTRUCTIONS_INTRO` 故意不收。** 它是「正文被预算裁掉了」时的告示语 —— 这时候正文根本不在帧里，换成强权限版等于对着一只空壳喊「指令生效中」。

### 预设里的身份单独打

0.2.x 的 `dsh-web-app/presets/*.patch.yml`（standard / ptc / minimal / cordis）各自带着 `persona.prefix`。预设跑在 agent scope，同名的 system-prompt 区段会遮蔽上一层 `cordis.patch.yml` 的注入 —— 只打顶层的话，用户切到「标准 / PTC / 极简」时跑的还是原来那个身份，前面的活全白干。

现在 presets 目录单独纳入靶点；`!!js` 动态拼身份的那份仍然跳过（改了会坏语法）。本机对一份真实 0.2.2 安装跑下来，靶点从 7 个涨到 11 个，打完 `grep "You are a coding agent"` 全仓 0 命中。

### 状态页：把「没问题的」也说一句

`--status` 默认只列要处理的文件。全部打完之后屏幕上只剩「目标 11 个」和一行 manual，看着像什么都没干。加一行汇总「N 个已是当前版，未逐条列出」，`--diagnose` 仍然展开全部。

### 桌面被搬走的机器

快捷方式这条线索原来只扫 `~\Desktop`。桌面是可以被搬走的（右键 → 属性 → 位置，或 OneDrive 接管），搬完之后 `~\Desktop` 要么不存在，要么是个早就没人用的空壳 —— 本机就是反例：`C:\Users\X\Desktop` 还躺着几百个旧文件，真桌面在 `I:\Desktop`，那边 49 个快捷方式一个都读不到。

现在桌面与开始菜单都先问注册表的 `User Shell Folders`（`REG_EXPAND_SZ`，含 `%USERPROFILE%` 的要展开），`~\Desktop` 降为兜底，公共桌面照旧。本机实测枚举到的 `.lnk` 从 59 个涨到 131 个。

### 两条新的定位来源

- **进程镜像路径**：以前只解析命令行。命令行是应用自己拼的字符串，壳把真 exe 藏进子进程参数时，命令行里出现的是父进程目录。改成先问内核要 `QueryFullProcessImageNameW`，命令行只当备胎。
- **卸载登记表**：装到自定义盘符、又没建快捷方式的机器，安装器写进注册表的 `InstallLocation` / `DisplayIcon` / `UninstallString` 是唯一还留着的书面记录。只读三处 hive（HKLM 64 / 32 + HKCU），显示名匹配上再向上校验安装根，几毫秒。

两条都只读、结果都进 `discover_app_root` 的缓存，`--status` 的来源标注会写「卸载登记表」。

### 命令行入口：`--menu` 真的能进菜单了

打包版不带参数双击默认开图形界面，命令行菜单靠 `--menu`。但判「要不要进菜单」只看了参数个数 —— `exe --menu` 是 2 个，`--menu` 又不算动作，于是一路落到检测流程：想看菜单，跑了一遍检测。现在 `--menu` 参与判定。

同一处还有三件事：

- 参数写错不再只丢一行英文 `unrecognized arguments`，改中文提示 + `--help` / `--menu` 引导（退出码仍是 2）。
- 把文件拖到 exe 图标上会被认出来并说明「本工具不吃拖放」，不再报参数错误。
- `--help` 底部的示例按当前载体显示命令名：打包版是 `pojia-ce.exe --status`，不再是 `python 破甲一键通.py`。

新增 `--pause`：跑完停一下等回车。冻结态下 `--help` / `--version` / 参数错误会自动停一次 —— 双击运行时控制台是本进程独占的，不停就什么都看不见。

### 图形界面卡在横幅第一行

`--gui` 打出这几行之后就没了，浏览器不弹、页面也打不开：

```
已启动图形界面，浏览器会自动打开；关掉窗口或按 Ctrl+C 即退出。
==================================================================
```

端口其实是活的（已经 bind），连上去只会超时 —— 进程卡在横幅第一行的 `print` 里，HTTP 服务连 accept 循环都没进。

原因是版本号。界面在打包态读不到 `.py` 源码，为了显示 `v8.62-CE` 会起一个 `exe --version` 子进程问自己。那个子进程继承了终端的 stdin，而 `--version` 退出前的留屏逻辑正在等一次回车 —— 没人按，父进程就干等在 `subprocess.run` 里。

两处一起改：

- 打包时把版本号摊成 `_version.txt` 一起塞进包，界面直接读文件，一次进程都不起。
- 留屏的判据加一条：stdout 也必须是终端。stdout 被管道接走时提示根本没人看得见，再等回车就是死等；双击运行时 stdout 是终端，照停不误。

## 下载

| 平台 | 文件 |
|---|---|
| Windows x64 | `pojia-ce-windows-x64.exe` |
| Windows x64（目录版） | `pojia-ce-windows-x64-onedir.zip` |
| Linux x64 | `pojia-ce-linux-x64` |
| macOS Apple Silicon | `pojia-ce-macos-arm64` |
| macOS Intel | `pojia-ce-macos-x64` |

校验和见同一 Release 的 `SHA256SUMS.txt`。脚本源码校验和：

```
2e9b22c4135bb791a81d5ca00ba2fd4a5079c12e1582043fcee6015113684270  src/破甲一键通.py  (572,006 B / LF)
```

**目录版是干什么的。** 单文件 exe 每次启动都要把自身解包到某个目录再运行，这一步在 Python 起来之前完成，失败就直接退出：

```
[PYI-12345:ERROR] Could not create temporary directory!
```

两个不同的原因会撞出同一行报错：

1. **解包目录不可写**。原来固定在 `%TEMP%`。现在 Windows 单文件版固定解到 `%LOCALAPPDATA%\pojia-ce\rt`，bootloader 会把整条路径自己建出来，父目录不存在也补得上 —— 把 `TEMP` / `TMP` 都指到不存在的盘再启动，产物照样跑。
2. **文件所在目录带低完整性标签**。这个更常见，也更容易误判成「程序坏了」。实测：同一个 exe 放在 `I:\Downloads` 报错，复制到 `I:\` 根目录就能跑；差别只有一处 —— 那个目录带着 `Low:(OI)(CI)(NW)`，继承给了里面每个 exe。

先看目录有没有标签：

```cmd
icacls "I:\Downloads"
```

出现 `Mandatory Label\Low Mandatory Level` 就是它。改回来：

```cmd
icacls "I:\Downloads" /setintegritylevel (OI)(CI)Medium
icacls "I:\Downloads\pojia-ce-windows-x64.exe" /setintegritylevel Medium
```

第一条只对以后进来的新文件生效，已经在里面的是第二条单独改。不想动 ACL 的话，把 exe 拖到 `I:\` 根、桌面或用户下载目录都行。

目录版把依赖放在 exe 旁边的 `_internal/`，一步都不碰临时目录、也不解包，启动最快。解压后整个文件夹一起用，别把 exe 单独拖出来。上面两条都撞上的机器走这一份。

## 升级

覆盖旧的脚本 / 可执行文件即可。本次改了 DSH 的靶点集合，**已破甲过 DSH 的机器建议重跑一次** `--target dsh`：新增的 presets 靶点会被补上，其余靶点判到「已是当前版」会静默跳过，不会重复写。其余目标未改动注入正文，不需要重跑。

## 已知限制

- 0.2.2 的分链预算只在 `--status` 里报口径，不参与判定 —— 预算够不够取决于用户自己的 `AGENTS.md` 有多大，本工具不改它的内容。
- `dsh-sdk-minimal` 的身份由 `!!js` 表达式动态拼，脚本不碰；要改请手动。
- 卸载登记表读的是当前用户的 hive；用管理员身份跑、且管理员是另一个账号时，看到的是那个账号的登记表。
