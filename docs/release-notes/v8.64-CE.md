# 破甲一键通 8.64-CE

**Windows 有安装包了：双击装完就能用，不用管理员，不再解包到临时目录。**

这一版只有一件事，但它是被一个真实的启动失败逼出来的。

## 起因：`Could not create temporary directory!`

单文件 exe 每次运行都要把十几 MB 解到 `%TEMP%\_MEIxxxxxx` 再启动。多数机器上没问题，但有些机器的安全软件不放行在临时目录里创建可执行文件 —— 程序还没开始跑，就死在解包这一步。让人去加白名单、关防护，是把工具的问题推给用户。

安装包不碰临时目录：依赖放在 exe 旁边的 `_internal/`，启动直接加载。

## 装什么、装到哪

下 `pojia-ce-windows-x64-setup.exe`，双击。

- 装到 `%LOCALAPPDATA%\pojia-ce`，**不需要管理员，不弹 UAC**。
- 装完有开始菜单项、设置里的卸载项，PATH 里也有 `pojia-ce` —— 命令行直接敲 `pojia-ce --status`，不用先 `cd`。
- `状态/`、`备份/` 不在安装清单里，升级和卸载都不动。

静默装：`pojia-ce-windows-x64-setup.exe /S`
指定目录：追加 `/D=D:\tools\pojia`（必须放最后，不加引号）

## 再装一次就是升级

安装程序先读 `HKCU\Software\Mladery\pojia-ce\InstallDir`：

- **有值** → 升级。目录页不显示（装到别处就成两份），标题变成「更新 破甲一键通：8.63 → 8.64」，装完刷新卸载项里的版本号。
- **没值** → 全新安装，默认目录 `%LOCALAPPDATA%\pojia-ce`。

程序自己也认得这个状态。`--update` 时：

| 形态 | 下什么 |
|---|---|
| 安装版（InstallDir 与自身目录一致） | `...-setup.exe`，静默覆盖 |
| 绿色版（其余） | 裸 `...-windows-x64.exe`，换掉自身 |

判定用目录比对而不是 exe 名 —— 把装好的 exe 复制到桌面，那份仍按绿色版处理，不会被安装包反过来覆盖。

安装版不能直接 `move` 覆盖：`_internal\*.dll` 在进程活着时被锁住。改成 `_update.bat` 轮询等自己真退出，再跑 setup，最后把程序拉起来。

## 卸载

设置 → 应用 → 破甲一键通，或装目录下的 `uninstall.exe`。

非静默卸载会问一句要不要先把改过的文件还原回去 —— 选「是」就对 DSH / WorkBuddy 执行 `--revert`。静默卸载（`/S`）默认不还原：安静的卸载不该顺手改别人的软件。

删文件前先验目录结构，`pojia-ce.exe` 和 `uninstall.exe` 都在才动手。

## 单文件 exe 仍然发

U 盘带走、不想装、临时用一次 —— 这些场景还需要它。Release 里两个都在，安装包标推荐。

## 验证

本地跑过完整一轮：静默安装到临时目录 → `_internal` 68 个文件齐全 → 注册表 `InstallDir` 正确 → `--version` 返回 8.64-CE → 静默卸载 → 目录清空、两个注册表项都没了。

CI 的 `windows-x64-setup` job 走同一套：打包 → 冒烟 `--version` / `--help` → 图形界面启动 → 编译 setup → 静默装到临时目录 → 比注册表 → 卸载 → 查残留。
